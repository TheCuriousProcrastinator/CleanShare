# CleanShare

A small native macOS app for sharing a clean, cropped version of your screen during presentations and video calls.

CleanShare lets you keep using your Mac normally while sharing only the part of the screen you want other people to see.

## Features

- Select a custom screen region to share
- Multi-display support
- ScreenCaptureKit-based capture
- Pause and resume sharing
- Black Screen mode
- Global panic shortcut
- Menu bar controls
- Launch at Login
- Remembers the selected capture area
- No third-party dependencies

## Why

CleanShare was built mainly for Microsoft Teams presentations where I want to keep the macOS menu bar and other parts of my desktop visible to me, but hidden from everyone else.

Instead of sharing the desktop directly, CleanShare creates a separate output window containing only the selected region. Share that window in Teams.

## Requirements

- macOS
- Screen Recording permission

## Privacy

CleanShare runs locally on your Mac. Screen capture is processed locally and is not uploaded anywhere by the app.

## Status

Personal project. Tested with Microsoft Teams on macOS.
